# Compatibility Matrix & Prerequisites

## Supported Operating Systems
| Operating System | Support Level | Notes |
| :--- | :--- | :--- |
| **Debian 11 / 12 / 13 (Trixie)** | Tier 1 (Primary) | Full support, tested natively |
| **Ubuntu 20.04 / 22.04 / 24.04** | Tier 1 (Primary) | Full support |
| **macOS (Darwin 12+)** | Tier 1 (Primary) | Full support via zsh/bash |
| **Windows 10 / 11 (WSL 2)** | Tier 1 (Primary) | Full support inside WSL Ubuntu/Debian |

## Shells
- `bash` (v4.0+)
- `zsh` (v5.0+)

## Minimum Prerequisites
- `git` (v2.20+)
- `curl` / `wget`
- `tar`
