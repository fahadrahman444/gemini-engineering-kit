# Gemini Engineering Kit 🛠️

Universal AI Agent Rules, Architecture Blueprints, and Production Skills for Google Antigravity & AI Pair Programmers.

---

## 📦 What's Inside

### 1. Global Master Rules (`rules/AGENTS.md`)
- **Ponytail Minimalist Philosophy:** YAGNI, standard library over dependencies, minimal diffs.
- **Anti-Slop Quality Guard:** Strict typing, zero dead code, no redundant `async/await`.
- **Dual-Process Thinking:** System 1 fast execution for simple tasks; deliberate System 2 planning for deep architectures.
- **Mobile-First & Performance:** $\ge$44px touch targets, collision-safe typography, no laggy `backdrop-filter: blur` opacity animations.
- **Async Concurrency:** Button mutation guards to eliminate double-click race conditions.

## 🚀 Quick Install on Any New Device

Run this single command on any machine (Debian, Ubuntu, macOS, or WSL):

```bash
mkdir -p ~/.gemini/config && cd ~/.gemini/config
git clone https://github.com/fahadrahman444/gemini-engineering-kit.git .
```

Or run the installer:
```bash
curl -fsSL https://raw.githubusercontent.com/fahadrahman444/gemini-engineering-kit/main/install.sh | bash
```

## 🔄 Syncing Updates

- **Push changes from this device:**
  ```bash
  cd ~/.gemini/config
  git add .
  git commit -m "update skills"
  git push origin main
  ```
- **Pull changes on another device:**
  ```bash
  cd ~/.gemini/config
  git pull origin main
  ```
